# Fiesta Juegos

Party web app: an invitation landing with registration (QR ticket + PIN) and touch-screen games for large interactive panels. **Pilot stage**: the GitHub Pages build runs in demo mode with fictitious guests and no backend.

- Landing: https://ggracis.github.io/fiesta-juegos/
- Panel app: https://ggracis.github.io/fiesta-juegos/play.html
- Touch diagnostics: https://ggracis.github.io/fiesta-juegos/diag.html

Code, scripts and design notes live in [app/](app/README.md).
